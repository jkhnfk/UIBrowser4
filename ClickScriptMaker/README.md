# Click Script Maker

`Click Script Maker`（点击脚本生成器）是一个独立的小型 macOS 应用：把鼠标移到任意程序的某个控件上，按 **⌘⌃⌥C**（或点击窗口里的按钮），它就会把你需要的 AppleScript / JavaScript 脚本生成出来，**并自动复制到剪贴板**，直接粘贴到脚本编辑器即可使用。

生成的脚本**不含屏幕坐标**：它通过辅助功能属性（`AXRole`、`AXTitle`、`AXDescription`、`AXIdentifier`、`AXValue` 等）和必要时同级元素序号去定位控件，所以窗口移动、缩放之后脚本仍然有效。

## 构建与安装

```bash
cd ClickScriptMaker
./build.sh              # 生成 build/ClickScriptMaker.app
./build.sh --install    # 生成并复制到 ~/Applications
```

`build.sh` 直接编译 UI Browser 4 项目中的 `ElementLocator.swift` 与 `ClickScriptGenerator.swift`，因此同一个功能只有一份代码，两个应用生成的脚本完全一致。应用含 `AppleScriptRoles.plist`（辅助功能角色 → System Events 类名映射），否则脚本里的类名会退化成 "UI element"。

## 使用方法

1. 双击运行 `ClickScriptMaker.app`。
2. 第一次运行时 macOS 会请求「辅助功能 / Accessibility」权限：勾选 Click Script Maker 的复选框（也可点窗口里的 **Open Accessibility Settings…**）。授权后应用会自动检测到，橙色提示条消失。
3. 把鼠标移到目标程序的控件上（按钮、菜单项、复选框、工具栏按钮……）。
4. 按 **⌘⌃⌥C**（在别的程序处于最前时同样有效），或者回到窗口点 **Capture Element Under Mouse**。
   - 按钮会先等待「Delay before capturing」设定的秒数（默认 3 秒，0 表示立即），方便你点完按钮再把鼠标移到目标控件上。
5. 脚本出现在窗口里并已复制到剪贴板；可切换 **AppleScript / JavaScript**，或 **Save Script…** 存成文件。

窗口里还会显示被捕获元素的辅助功能路径（如 `window "文档" > group "工具栏" > button "重新载入"`）、所属程序名与 bundle ID，并在同级元素无法区分时给出橙色警告。

### 菜单栏与窗口

- **Window > Click Script Maker（⌘0）**：重新显示窗口。
- **Window > Capture Element Under Mouse**：菜单版的捕获按钮（快捷键 ⌘⌃⌥C 由全局热键注册，不放在菜单里，以免重复触发）。
- 关闭窗口**不会**退出程序，全局热键继续有效；点 Dock 图标或 ⌘0 可以把窗口找回来。退出请用 ⌘Q。

## 注意事项

- 如果 UI Browser 正在运行，两者都想注册 ⌘⌃⌥C：后注册的一方会失败（日志中会提示）。此时请用按钮捕获，或先退出其中一个程序。
- 应用用本机的 `Apple Development` 证书签名；如果改了代码重新构建，只要签名证书与 bundle ID 不变，辅助功能授权会保留；若换用 ad-hoc 签名（找不到证书时），每次构建后需要重新授权。
- 如果鼠标停留在 Click Script Maker 自己的窗口上，捕获前窗口会临时隐藏 0.25 秒，确保被捕获的是鼠标下面真正可见的那个控件（通常是它后面那个程序的控件）。
- 脚本通过 System Events 操作目标程序，因此**运行**生成的脚本时，执行脚本的程序（Script Editor、`osascript`、快捷指令等）也需要辅助功能权限。
- 脚本头注释里仍写着 "Generated by UI Browser 4"：生成器与 UI Browser 4 共用同一份源码，因此两个程序输出的脚本完全一致。注释不影响运行，可按需删改。
- 已通过的验证：`build.sh` 编译通过；窗口布局无约束冲突（用离屏 harness 逐层检查 frame / `hasAmbiguousLayout`）；生成的 AppleScript 与 JavaScript 都能被 `osacompile` 正常编译；未授权时捕获会弹出说明性警告而不是崩溃。**实际点击**未能在本机自动验证，因为命令行环境没有辅助功能授权，请在应用内授权后自行试用。
